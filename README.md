# GridSQL-Gen

GridSQL-Gen is a lightweight browser-based SQL generator for creating `UPSERT` scripts for the `grid_views_v2` table.

It provides a clean UI to generate SQL blocks for Grid Views with support for:

- Shared configuration
- Default views
- GraphQL filters
- Pagination settings
- ViewDetails JSON
- SQL export/download
- Clipboard copy
- Dynamic SQL preview with syntax highlighting

---

## ✨ Features

- ⚡ Generate SQL instantly
- 🎨 Modern dark-themed UI
- 🧩 Add multiple view entries
- 🔍 GraphQL filter builder
- 📋 Copy generated SQL
- ⬇️ Download `.sql` file
- 🗑️ Remove or clear view entries
- 🧠 SQL syntax highlighting
- 🛠 UPSERT pattern support

---

## 📸 Preview

- Right panel for real-time generated SQL output
